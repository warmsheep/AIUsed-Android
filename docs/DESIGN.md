# 设计说明

## 调研的社区方向

2026 年的 AI 用量 / 开发者工具界面，社区里比较成熟的视觉方向集中在以下几类：

- **Dark glassmorphism dashboard**：深色底 + 低透明度玻璃卡片 + 大圆角 + 单个高饱和强调色。Dribbble 的 `dark glassmorphism`、`glassmorphism dashboard` 标签下大量案例采用这种结构。
- **Usage / quota dashboard**：核心不是表格，而是“大数字 + 环形/条形仪表 + 状态色”。Dribbble 的 `usage dashboard`、`quota dashboard` 搜索结果普遍把“剩余百分比”作为第一视觉层级。
- **Mobile finance / credit card**：额度卡片借鉴信用卡账单的层级：供应商身份 → 主指标 → 多窗口明细；红→绿渐变是金融类额度产品最常见的风险表达。
- **Widget-first 设计**：小米 HyperOS 与 ColorOS 的小组件偏好深色、圆角、信息密度低、可缩放；我们用 4×2 作为主尺寸，2×2 自动降级为单供应商。

## 本项目的设计决策

### 1. 统一四格，而不是按供应商定制布局

每个供应商卡片固定包含：5 小时、本周、本月、余额。接口不提供的类型保留完整格子，只把内容置灰并显示“未提供此额度”。这样：

- 纵向浏览时每个卡片的视觉节奏一致；
- 用户不需要记忆“这家有没有月额度”；
- 新供应商接入时不需要重做布局。

### 2. 红 → 绿渐变是“剩余量”的语义

额度条的渐变从左到右固定为红 → 橙 → 黄 → 绿，填充宽度等于剩余百分比。绿色从剩余 60% 开始，覆盖刻度后 40%，对应“剩余 60% 是安全期”的判断；数值 ≥60% 时文字也转为绿色。

- 0%：`#FF4D5E`
- 40%：`#FFA23A`
- 70%：`#FFD34E`
- 100%：`#41E6B0`

大数字颜色也按同一套插值取色，避免“条是红的、数字是白的”的割裂。

### 3. Aurora 背景 + 玻璃卡片

- 背景不是纯黑，而是 `#07090F → #0B1020` 的纵向渐变，叠加紫、青、蓝三个低透明度径向光晕。
- 卡片使用 26dp 圆角、1dp 白色 8% 描边、半透明深色底；阴影很轻，靠描边和层级而不是重投影区分。
- 强调色只使用薄荷绿一个主色，紫/蓝只出现在品牌徽章和背景光晕里。

### 4. 信息层级

1. 顶部：产品身份 + 全局刷新/设置
2. Hero：综合余量、健康供应商数、需要关注数、最近更新时间
3. 供应商列表：单卡内先看状态和异常，再看四格
4. 底部：添加供应商 + 安全说明

异常信息不弹窗打断，而是贴在对应卡片顶部，点击即可重试；旧数据会保留并标记“数据过期”。

### 5. 小组件

- 深色与浅色两套 Aurora 渐变背景，跟随 App 的主题设置；选择「跟随系统」时随系统切换。
- 浅色模式使用深色文字、浅色轨道；额度条保持与深色模式相同的明亮红→绿渐变，和主 App 的浅色额度条完全一致。
- 使用 `SizeMode.Exact` 读取桌面真实高度；供应商以三列卡片网格排列，每张卡片内部把 `5H / 周 / 月` 三条横向额度条纵向堆叠，价格/套餐作为卡片副标题。
- 卡片高度由本机字体度量动态计算（Paint.FontMetrics + fontScale），不再设置固定卡片高度；列距 8dp、行距 7dp、外边距 15/10dp 固定。高度决定能放下几行卡片，不会把卡片拉高、移动或重新分配空间。
- 4×2 显示一行 3 家，通过标题栏 `‹` / `›` 翻页；最后一页不足 3 家时用“＋ 添加供应商”占位，保证卡片宽度和位置不跳动。2×2 自动降级为单列单家。
- 高度每多一行增加 3 张卡片；3×4 起至少两行，具体行数由桌面实际高度决定。空槽位显示可点击的添加提示。
- 卡片不再设置固定高度，避免第一行“月”条越过卡片内容边界被下一行遮住或裁剪。
- 每条额度用一张 256px 的平滑渐变 Bitmap 绘制，按百分比把未填充像素设为透明，并用圆角矩形裁剪成和主 App 一致的圆角胶囊；三列每行只有 5 个直接子元素，避开 Glance 最多 10 个子元素的限制，99% 精确显示为 99%。
- 右上角刷新按钮触发 WorkManager 一次性任务；点击供应商卡片或标题打开 App。
- 翻页状态存入 Glance state（`updateAppWidgetState`），由 `currentState()` 驱动重组；翻页 action 携带当前容量参数，按容量分页。缓存/主题刷新会 bump 一个 Glance state 版本号，避免 RemoteViews 复用旧会话导致不刷新。
- 标题栏左右翻页和刷新都使用 48dp 方形触摸区，视觉字号仍保持紧凑，避免小箭头难以点击。
- 空槽位使用低对比度的“＋ 添加供应商”卡片，点击打开 App；既提示可扩展容量，也避免大块无意义留白。

## 可访问性

- 主要点击目标不小于 40dp，额度格子文字保持 1 行并允许系统字体缩放。
- 不只依赖颜色表达状态：同时有“正常 / 额度偏低 / 数据过期 / 异常”文字。
- 浅色模式使用独立的对比度配色，而不是简单反色。
